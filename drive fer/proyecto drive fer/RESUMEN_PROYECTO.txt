## 🔄 Flujo de Datos

```
1. INICIALIZACIÓN
   ├─ Config carga variables de entorno
   ├─ ProjectScheduler instancia managers
   ├─ Managers se autentican con Google APIs
   └─ Sistema listo para operar

2. CREACIÓN DE ESTRUCTURA (Primera ejecución)
   ├─ DriveManager crea carpeta raíz
   ├─ Para cada departamento:
   │  ├─ Crea carpeta del departamento
   │  ├─ Crea subcarpeta "Clientes"
   │  └─ SheetsManager crea Spreadsheet
   ├─ SchedulerManager inicializa headers
   └─ Se crea Cronograma Maestro

3. AGREGAR PROYECTO
   ├─ Usuario proporciona datos
   ├─ ProjectScheduler valida
   ├─ SheetsManager escribe en departamento
   └─ Se registra en log

4. CONSOLIDACIÓN
   ├─ SchedulerManager lee todos los departamentos
   ├─ Combina datos en una estructura
   └─ SheetsManager escribe en Cronograma Maestro

5. MONITOREO
   ├─ NotificationManager verifica correos
   ├─ Detecta plazos próximos
   └─ Genera alertas y registra eventos
```
